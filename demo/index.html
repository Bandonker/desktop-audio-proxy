Security and capability boundaries

Handled by the package

  • Audio, video, range requests, and bounded HLS rewriting
  • Race-safe switching for existing media elements
  • Private-address and redirect destination validation
  • Optional exact-host and wildcard-subdomain allowlists
  • Loopback-only host defaults and bounded metadata cache

Owned by the host application

  • Starting the Node process or Tauri sidecar
  • Authentication, authorization, and rate limiting
  • DRM, site scraping, and streaming-service APIs
  • Codec installation, transcoding, and device routing
  • Station catalog policy and trusted CDN host inventory

Copy-paste integration

import { createMediaElementController } from 'desktop-audio-proxy/browser';

const radio = createMediaElementController(audioElement, {
  proxyUrl: 'http://127.0.0.1:3002',
  autoDetect: false,
  fallbackToOriginal: false
});

await radio.load(stationUrl);
// The listener can now press the existing media controls.
// On teardown:
await radio.dispose();
import { startProxyServer } from 'desktop-audio-proxy/server';

const proxy = await startProxyServer({
  host: '127.0.0.1',
  port: 3002,
  corsOrigins: ['http://localhost:5173'],
  allowedHosts: ['stream.example.com', '*.trusted-cdn.example'],
  allowPrivateAddresses: false
});

// On host shutdown:
await proxy.stop();
// React
const { playableUrl, loading, error } = useAudioUrl(stationUrl, {
  proxyUrl: 'http://127.0.0.1:3002',
  fallbackToOriginal: false
});

// Vue
const { audioUrl, isLoading, error } = useAudioProxy(stationUrl, {
  proxyUrl: 'http://127.0.0.1:3002',
  fallbackToOriginal: false
});
